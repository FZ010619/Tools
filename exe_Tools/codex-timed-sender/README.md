# Codex 队列投递器

一个按需启动的 Windows 小工具：提前编辑多条消息，在 Codex 额度恢复后按顺序投递到你明确绑定的 Codex / ChatGPT 桌面应用窗口。

## 下载与运行

在 Releases 下载 `CodexTimedSender.exe` 后直接运行，无需安装 Python。

## 从源码运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 构建可执行文件

```powershell
python -m pip install -r requirements-build.txt
./build.ps1
```

生成的文件位于 `dist/CodexTimedSender.exe`。构建产物默认被 Git 忽略，请通过 GitHub Release 分发。

## 使用

1. 在 Codex 的“设置 → Usage”查看额度恢复时间。
2. 打开目标 Codex / ChatGPT 对话，在小工具点击“3 秒后绑定当前窗口”，并在倒计时内切换到该对话。
3. 编辑一条消息后点击“加入队列”。本地文件以路径清单发送；图片会作为剪贴板附件粘贴。可继续添加、选择编辑、删除或调整顺序。
4. 填入额度恢复时间和每条消息的间隔（默认 15 秒），然后点击“保存并启动队列”。
5. 到点后会自动发送最早的待发送消息；成功后等待设定间隔再发送下一条。
6. 发生窗口或粘贴错误时，当前消息标记为“发送失败”，队列会暂停且内容保留。修正后重新绑定窗口，点击“继续 / 重试”。

“首条发送后等我确认再继续”适用于你希望先人工确认额度真的恢复的情况；勾选后，第一条成功投递后需要点击“继续 / 重试”才会发送后续消息。

消息队列和恢复时间仅保存在本机：
`%LOCALAPPDATA%\CodexTimedSender\queue.json`。关闭程序不会后台驻留；下次打开会恢复队列，但必须重新绑定目标窗口。

## 限制

- 仅支持 Windows，且 Codex / ChatGPT 与本程序应以相同权限运行。
- 该工具不能、也不会读取你的账号、Cookie、登录凭据或 Codex 界面来查询额度；恢复时间需从“设置 → Usage”手动填写。
- 本地文件仅发送路径。目标 Codex 项目是否能够读取该路径取决于其项目目录与权限。
- 发送会覆盖系统剪贴板内容。
- Windows 可能阻止后台程序强制切换前台窗口；程序会在无法激活目标窗口时停止该条投递，不会继续误投递。

## 隐私与安全

- 不联网，不收集或上传数据。
- 仅在你明确绑定的单一窗口存在且可激活时才发送。
- 请勿在待发送文本中放入密码、令牌或其他不应发送给聊天服务的敏感信息。
